Entrants write a single joke about Monday mornings, no longer than 200 characters, and submit that text as their entry. A judge model reads the jokes two at a time and picks the funnier one, weighing whether the joke is really about Monday mornings, whether the punchline lands, surprise, economy of words and freshness.

## Run it

```sh
python3 main.py
```
